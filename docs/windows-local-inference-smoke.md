# Release smoke: local GGUF on Windows x64

Run on a real Windows x64 machine with sufficient RAM for a small chat GGUF. Use a disposable standard-user account, Developer Mode off, and a Desktop project path containing spaces. Record Windows, CPU, engine and Desktop versions, runtime build, model filename, and results. Building the Windows installer or listing a cached model does not establish that inference works.

1. Start Desktop from the Start menu. In **Settings → Updates**, install or select the candidate engine. The engine, not Desktop's Hugging Face download helper, launches llama.cpp. In the matching engine's interactive CLI, `/setup llama-cpp` installs its verified runtime on supported releases. Alternatively, install the official x64 CPU llama.cpp distribution **with its DLLs together**, set the user variable `DIAL_LLAMA_SERVER` to the full `llama-server.exe` path, and relaunch Desktop after the new environment takes effect. Do not use MLX weights for this test.
2. In the model library download a single-file instruct GGUF (for example the suggested Qwen2.5-Coder 1.5B Q4_K_M). Confirm the download is listed with a nonzero size after Reload, including in an account without symlink privileges. Start a fresh engine session if needed to refresh its model inventory.
3. With no turn running and the model cold, select that exact local model in the composer. Before sending text, check for visible load state and a new `llama-server.exe` in Task Manager. Once the composer enables Send, ask `What is 6 times 7?`. Confirm progress gives way to generated text and completes; then send a second prompt in the same session. A status label alone is not a pass.
4. Quit Desktop and its engine. In the disposable account, temporarily point `DIAL_LLAMA_SERVER` at a nonexistent `.exe`, start Desktop with that environment and repeat the selection and send. Confirm the failure is visible and the session is not stuck loading. Restore the previous variable (remove it if previously unset), restart and verify successful inference again.
